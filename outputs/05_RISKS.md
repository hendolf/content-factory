# Реестр рисков v1.0

Вероятность и влияние — предварительная экспертная оценка, не статистика. Владелец риска назначается как роль; конкретные имена фиксируются при старте.

| ID | Риск | Вероятность / влияние | Ранний сигнал | Мера и резервный путь | Ответственный |
|---|---|---|---|---|---|
| R01 | Есть просмотры, но услуга не нужна покупателю | Высокая / высокое | Нет квалифицированных обращений или оплаты | Интервью, конкретный оффер, платный пилот, лимит времени до решения | Владелец продукта |
| R02 | Ручная редактура съедает маржу | Высокая / высокое | Растут часы на согласованный материал | Учёт полного цикла, шаблоны из реальных фактов, ограниченный пакет, пересчёт цены | Руководитель услуги |
| R03 | Meta app review/scopes или тип аккаунта не подходят | Средняя / высокое | 403, нет нужной функции | Проверка до адаптера; ручная публикация; не обещать сроки approval | Разработчик интеграций |
| R04 | TikTok Direct Post не проходит intended use/audit | Высокая для внутреннего инструмента / высокое | Private-only, отказ или несовместимый UX | Ручная публикация либо проверенный разрешённый провайдер; не делать критическим каналом | Владелец продукта |
| R05 | Metricool подключён в чате, но серверного доступа нет | Средняя / высокое | Нет API-тарифа/токена/нужной сети | Различать MCP и API; уточнить условия; прямой Telegram либо ручной путь | Владелец + разработчик |
| R06 | Изменения API/лимитов/метрик | Высокая / среднее | Ошибки, исчезнувшие поля | Версии контрактов, дата проверки, capability flags, unsupported вместо 0 | Разработчик интеграций |
| R07 | Повторная публикация после таймаута | Средняя / высокое | Нет ответа, но пост уже появился | unknown и сверка, уникальные задания, без слепого повтора | Разработчик backend |
| R08 | Данные/токены одного клиента доступны другому | Средняя / критическое | Запрос по чужому ID проходит | RLS, составные ключи, тесты всех маршрутов/экспортов/медиа/worker; стоп подключения клиентов при сбое | Технический ответственный |
| R09 | ИИ выдумал цену, кейс, гарантию или отзыв | Высокая / высокое | Нет источника утверждения | Версионные факты и проверка редактором; блок согласования неизвестных обещаний | Редактор |
| R10 | Нет прав на фото, музыку или персональные истории | Средняя / высокое | Источник/разрешение не указан | Использовать разрешённые оригиналы; запрет выпуска до подтверждения прав | Редактор + владелец бренда |
| R11 | Региональные, рекламные или правовые ограничения | Не оценена / высокое | Неясно, можно ли размещать оффер/хранить контакты | Проверить применимые официальные правила по фактической юрисдикции до запуска; при необходимости специалист; альтернативный канал | Владелец бизнеса |
| R12 | Ошибочная атрибуция и двойной учёт лидов | Высокая / среднее | Несколько кампаний на одного человека | События, явное правило, дедупликация внутри клиента, unknown/со слов; без ложного ROI | Аналитик |
| R13 | Долгий цикл паркетной сделки даёт ложный отрицательный вывод | Средняя / среднее | Заявки есть, оплаты ещё нет | Отдельные стадии, 30–60 дней наблюдения после контент-пилота | Менеджер продаж |
| R14 | Заявки не обрабатываются человеком | Средняя / высокое | Нет первого ответа в рабочий день | Назначить ответственного, ежедневная очередь и просрочки | Менеджер продаж |
| R15 | Неуправляемые расходы ИИ/видео | Средняя / высокое | Ускоренный расход бюджета | Лимит бренда/дня, оценка перед вызовом, стоп новых вызовов, видео вручную | Технический ответственный |
| R16 | Очередь перестала работать, бэкап не восстанавливается | Средняя / высокое | Просроченные задания, отсутствует свежий бэкап | Health checks, сигналы оператору, пробное восстановление, ручная публикация | Ответственный за эксплуатацию |
| R17 | Вредные инструкции внутри внешнего текста | Средняя / высокое | Черновик пытается вызвать действие/раскрыть данные | Внешние тексты только как данные, ограниченный контекст, структурированный вывод, серверная авторизация действий | Разработчик ИИ |
| R18 | Поиск обсуждений даёт нерелевантный шум | Высокая / среднее | Мало принятых карточек | Замер релевантности, ручная выборка; не превращать всё найденное в лиды | Редактор/маркетолог |
| R19 | Разработка расползается на SaaS, CRM и финансового агента | Высокая / высокое | Задачи без связи с проверкой дохода | Связь каждой задачи с FR/воротами; отдельный backlog; финансовый агент исключён | Владелец продукта |
| R20 | Ошибочная интерпретация старого чата | Средняя / среднее | Новая работа противоречит недоступному решению | Отмечать пробелы, сверять при получении исходной вкладки; текущий запрос — основа v1.0 | Владелец продукта |

Остаточные риски: approval и доступность API нельзя гарантировать; нельзя полностью устранить неопределённость внешней отправки; качество контента и продажи зависят от участия людей. Эти ограничения включаются в договорённости о пилоте и отчёт, а не скрываются за словом «автоматизация».

Перед публичным коммерческим запуском R08, R09, R10 и R11 должны иметь конкретного ответственного и выполненную проверку. Это проектные условия готовности, не утверждение о действующих юридических запретах.
