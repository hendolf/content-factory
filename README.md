# Content Factory

Рабочий проект развития личного бренда `@tvh_channel` в Threads с последующей проверкой консультаций или лидогенерации и переносом системы на другие бизнес-направления.

## Текущий этап

Первый пилот — личный Threads. Публикации согласует владелец, входящие диалоги поступают в Telegram. Автоматические комментарии и личный финансовый агент не входят в MVP.

## Безопасность

Не добавлять в репозиторий пароли, API-токены, коды подтверждения, документы, необезличенные личные переписки и приватные клиентские материалы. Большие фото и видео хранить отдельно в облачном хранилище; в проекте сохранять только описание, права использования и ссылку с контролируемым доступом.
