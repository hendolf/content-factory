## Зафиксированные решения

Один коммерческий продукт с изоляцией клиентов и брендов. Четыре направления платформ: Threads, Instagram, Telegram, TikTok. Полный цикл: база знаний → контент → согласование → публикация → аналитика → обращения → сделки → следующий эксперимент. Первый пилот: личный бренд владельца в Threads. Цель — найти работающие темы и механику роста, получить первые входящие обращения и на накопленном опыте проверить переход к консультациям или услуге лидогенерации из Threads. Паркетное направление подключается вторым этапом. Многоклиентская модель начинается с первой схемы данных; сложный самостоятельный SaaS и биллинг отложены до подтверждения спроса.

Первый продаваемый формат — управляемая услуга на базе системы: настройка бренда, производство согласованных материалов, организация публикаций и отчёт по обращениям. Это проектное решение, а не уже подтверждённая готовность рынка платить. Прибыль и поток заявок не гарантируются.

Начинать с контента и измеримой воронки. Автоматическую отправку комментариев, холодных личных сообщений и массовые действия не включать в MVP. Личный финансовый агент не является частью продукта. Учёт затрат и выручки Content Factory нужен только для экономики услуги.

## Контекст и пределы проверки

Прочитан доступный исходный чат «Утренний разбор Threads» через read_thread: возвращены пять последних доступных ходов, older cursor отсутствует. В нём подтверждены желание пользователя строить доходную систему, несколько клиентских направлений и прежняя работа с Metricool. Несколько ответов представлены только ссылками-заглушками. Отдельная вкладка «Роадмап ИИ агента» не была получена и не считается изученной. Решения из текущего запроса имеют приоритет; новые проектные рекомендации явно обозначены как таковые.

Исторический brandId 7423237 найден в старом ответе, но не проверен на актуальность. Попытка прочитать бренды через подключённый Metricool завершилась транспортной ошибкой. Тариф, доступные аккаунты, разрешения, фактические метрики и активные задания не подтверждены. Никакие посты и настройки аккаунтов в ходе этой работы не менялись.

Проверка официальных публичных источников выполнена 21.10.2026. Основной сайт документации Meta вернул HTTP 429, поэтому для подтверждённых возможностей использованы официальные коллекции Meta в Postman. Это первичные источники, но они сами предупреждают о неполноте относительно changelog. Перед реализацией обязательна повторная проверка документации и доступов. «Подтверждено документацией» не означает «работает на нашем аккаунте».

## Следующий шаг

Собрать минимальный пакет материалов личного бренда по [чек-листу владельца](07_OWNER_INPUT.md). Параллельно выполнить CF-001 и CF-002: обследовать проект, снять исходные показатели личного Threads и проверить Telegram без публичных записей. Не покупать новые сервисы до проверки существующих доступов. Паркетные материалы пока можно складывать в резерв, не задерживая первый пилот.
